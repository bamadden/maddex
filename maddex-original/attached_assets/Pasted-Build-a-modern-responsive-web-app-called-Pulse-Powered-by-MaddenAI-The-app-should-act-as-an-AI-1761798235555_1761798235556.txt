⚙️ FUNCTIONALITY
Use fetch() to call live crypto data from CoinGecko API and stock market data from Polygon.io (use free endpoints).
For news, use dummy static JSON array for now.
Chat page connects to your Express backend:
app.post('/api/ai', async (req, res) => {
  const userInput = req.body.query;
  const response = await fetch('https://api.openai.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${process.env.OPENAI_API_KEY}`
    },
    body: JSON.stringify({
      model: 'gpt-4-turbo',
      messages: [{ role: 'user', content: `Give a financial insight for: ${userInput}` }]
    })
  });
  const data = await response.json();
  res.json({ answer: data.choices[0].message.content });
});
