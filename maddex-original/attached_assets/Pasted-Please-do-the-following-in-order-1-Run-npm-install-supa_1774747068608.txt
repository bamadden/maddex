Please do the following in order:

1. Run: npm install @supabase/supabase-js

2. Add the file maddex_auth.js from the src folder into the app.
   Import these from ./maddex_auth:
   onAuthChange, getSession, signIn, signUp, signOut,
   getPortfolio, addToPortfolio, removeFromPortfolio,
   updateShares, getWatchlist, addToWatchlist,
   removeFromWatchlist, searchAssets, calculatePortfolioValue,
   getAssetTypeLabel, getAssetTypeColor

3. AUTH FLOW:
   On app load call getSession() — if a session exists go
   straight to the main app. If no session, show a Login screen.
   Use onAuthChange() to listen for login/logout events and
   update the app state accordingly.

4. LOGIN SCREEN — shown when not authenticated:
   Full screen dark background matching the Maddex design.
   - Maddex logo and "Powered by MaddenAI" at the top
   - Toggle between Login and Create Account
   - Create Account fields: Full Name, Email, Password
   - Login fields: Email, Password
   - Primary action button (Login / Create Account)
   - Forgot password link under the password field
   - After signup show: "Check your email to verify 
     your account before logging in"
   - Show inline error messages below the relevant field
   - Show a loading spinner on the button while authenticating

5. PORTFOLIO SCREEN — replace static data with live Supabase:
   On mount load holdings from getPortfolio(userId)
   Calculate live values via calculatePortfolioValue(portfolio, marketData)

   ADD HOLDING:
   - Floating + button in the bottom right of the Portfolio screen
   - Tapping it opens a modal with a search input
   - As user types (from 1 character) show a dropdown of
     results from searchAssets(query) — max 8 results
   - Each result shows: asset name (bold), ticker (muted, 
     right side), asset type badge coloured by getAssetTypeColor()
   - Tapping a result selects it and shows a shares input
   - Shares input accepts decimals for crypto (e.g. 0.5 BTC)
   - Save button calls addToPortfolio(userId, asset, shares)
   - Close/cancel button dismisses the modal

   HOLDINGS LIST:
   Each holding card shows:
   - Asset name and ticker symbol
   - Number of shares held
   - Current live price (from marketData)
   - Total current value (shares x live price)
   - 24h change in % and dollar amount (green/red)
   - Allocation % of total portfolio
   - Long press to delete via removeFromPortfolio()
   - Tap to edit number of shares via updateShares()

   PORTFOLIO TOTAL at the top:
   - Total portfolio value
   - Total 24h change in dollars and %
   - Number of holdings

6. WATCHLIST — same smart search as portfolio:
   - Add to watchlist via addToWatchlist()
   - Remove via removeFromWatchlist()
   - Load on mount from getWatchlist(userId)
   - The Add to Watchlist button in AI Chat response cards
     should call addToWatchlist() and save to Supabase

7. ACCOUNT TAB — add to bottom navigation:
   Add a 5th tab with a person icon labelled "Account" showing:
   - User's full name and email at the top
   - Subscription tier badge (Trial / Core / Prime / Apex)
   - Edit profile section with dropdowns for:
     knowledge level, risk profile, income bracket, goals
   - Newsletter preferences toggle
   - Sign out button at the bottom calling signOut()
   - After sign out return to the Login screen

8. SESSION PERSISTENCE:
   Supabase handles this automatically — just make sure
   getSession() is called on every app load so returning
   users go straight to the main app without logging in again
