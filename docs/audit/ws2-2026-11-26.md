## Second pass (26 Nov 2026, after the fixes above)

A fresh code read of today's changes. Every item was fixed the same day:

- **H1:** CUSTOM ◀ ▶ (and dragging) could put a 2-wide widget on top of its
  neighbour. A swap is now refused if either widget would land on a third
  (`gridPlacement.js`). A test runs every swap of the default layout.
- **M1:** ARRANGE ◀ ▶ swapped with hidden panels, so nothing visible moved.
  They now step among visible panels only.
- **M2:** a restored view's Dashboard dense mode was lost when the Dashboard
  was on CUSTOM. Intents are now taken a tick later, so a component the change
  mounts can still read them.
- **M3:** module state was lost when a restored view changed the layout. The
  layout is now applied first, the intent is left for the remount, and the
  event follows a tick later.
- **M4:** the split view's second pane and divider were not saved. Now they
  are.
- **M5:** company pages were not kept in saved views, though the benchmark
  said so. They now record their company.
- **M6:** a background tab kept a visit open overnight. Visits now continue
  only while the tab is visible.
- **L1 and L2:** a restored value skipped the module's own save, and the
  Watchlist's manual order (null) was ignored. `useIntentState` now takes a
  `persist` callback and treats a field that is present but null as a value.
- **L3:** Scanner validates a restored tab.
- **L4 and L5:** an old-format visit record no longer reads as a first visit,
  and a clock set back no longer keeps a visit open.
- **L6:** hiding the SINCE panel no longer stops visit tracking. The Overview
  tracks the visit.
- **L7:** "delete view" now needs the exact name.
- **L8:** a pending "would drop" confirmation clears on any other command.
- **L9:** "rename view" splits at an existing view's name.
- **L10:** the CUSTOM edit buttons are 44 px.
- **L11:** autosave no longer overwrites while "Restore your last session?" is
  asking, and it also saves when the tab is hidden or closed.

Still open: editing CUSTOM widgets at phone width (the empty-cell grid
assumes the saved column count).
