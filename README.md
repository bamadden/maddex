# Maddex — Financial Intelligence

Bloomberg-style financial terminal for Australian investors, powered by MaddenAI.

## Stack
React 19 + Vite + TanStack Query + Axios + D3 + Recharts + Tailwind CSS + IBM Plex Mono

## Modules
Markets · Portfolio · Crypto · FX · Macro · Watchlist · News · Global Intelligence

All prices shown in AUD by default. Live data only — no placeholder prices.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
